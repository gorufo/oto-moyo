# oto-moyo（音の出るジェネレーティブ模様）

画面をなぞると、その軌跡に沿って幾何学模様が育つ小さなアート作品です。色は時間とともにゆっくり変化し、クリック（タップ）で効果音が鳴ります。左右対称のミラー描画でカレイドスコープのような模様になります。

依存パッケージやビルドは不要。単一の HTML ファイルだけで動きます。

## 使い方

`index.html` をブラウザで開くだけです。

```bash
# 例: 簡易サーバーで開く場合
python -m http.server
# → http://localhost:8000/index.html
```

## 操作

| 操作 | 内容 |
| --- | --- |
| ドラッグ / スワイプ | 模様を描く |
| クリック / タップ | 効果音を鳴らす |
| `C` | キャンバスをクリア |
| `S` | PNG として保存 |
| `H` | パネルの表示切り替え |
| `Space` | 音のオン / オフ |

画面下のツールバーからも同じ操作ができます。

## 技術メモ

- 描画: Canvas 2D（`globalCompositeOperation = 'lighter'` で加算合成）
- 音: Web Audio API（ペンタトニックスケールのランダムな音、ステレオパン付き）
- 色: HSL の色相を `performance.now()` でゆっくり回転
